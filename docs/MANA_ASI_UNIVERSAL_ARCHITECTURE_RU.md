# MANA Genesis 4.0 — целевая реализация для realme RMX5566RU и правило одного нажатия

Статус: обязательная продуктовая спецификация и план реализации. Документ не объявляет неподтверждённые функции готовыми.

## 1. Единственная целевая платформа этого релиза

Целевой аппарат: **realme RMX5566RU / RE645F**, аппаратная ревизия RMX5566_11, Android 16 / API 36, realme UI 7.0, Qualcomm Snapdragon 685 (SM6225, bengal), ARM64, Adreno 610, kernel 5.15.197-android13, locked bootloader, AVB 1.2, green Verified Boot, динамические разделы, A/B slot.

Не расширять эту задачу до «любой Android 12+», универсальной OEM-матрицы или поддержки Samsung/Xiaomi/Huawei и т.п. Не использовать профиль realme C85 5G / Dimensity 6300. Не заявлять совместимость даже с другой моделью realme без отдельного аппаратного тестирования. Android API-совместимость библиотек сама по себе не означает поддержку другого устройства.

До сборки прошивки необходимо подтвердить точную разметку разделов, device tree, kernel source/config/DTS/DTBO, vendor blobs, VINTF/HAL, AVB signing chain, recovery/restore path и возможность официальной разблокировки загрузчика. Если чего-то нет — фиксировать блокер, не подменять догадками.

## 2. Продукт: одна MANA, один Brain, одно приложение

- MANA Brain — центральный интеллект и владелец задач/памяти/планирования.
- MANA OS — управляемая Brain системная среда; телефон — аппаратное тело.
- Один основной APK MANA, а не набор дублирующих AI-приложений и не просто лаунчер.
- Локальная модель LiteRT-LM — основной офлайн-движок; локальная память и журнал задач; облачные модели OpenAI, Anthropic, Google Gemini, xAI и другие — необязательные подключаемые провайдеры. Никаких обязательных платных API или ключей.
- Голосовой русский интерфейс, анимированный 3D-аватар MANA, фиксированные лицо/голос и сменные наряды/аксессуары; тёмно-синяя тема.
- Сохранить все согласованные модули: адаптивное обучение и исследование интернета с локальной базой знаний; Diary; Future Updates; безопасное саморазвитие; Smart Receptionist, Contact Intelligence, Life Manager; Yandex/VK; Game Intelligence/Minecraft; подключение часов, наушников и автомобиля по разрешённым API.
- Smart Receptionist: playful; задержка автоответа 10 секунд; сводки разговоров включены; отдельная обработка неизвестных номеров. Звонки/сообщения выполняются только с системными разрешениями и подтверждением владельца, где требуется.
- Максимальная автономность означает самостоятельное выполнение безопасных локальных задач, но не обход системных разрешений и не совершение последствий без согласия владельца.

## 3. Главное UX-требование: ONE ACTION

После того как владелец штатно установил APK, на главном экране должен быть один крупный элемент **«ЗАПУСТИТЬ MANA»**.

После одного нажатия MANA автоматически:
1. Проверяет целостность APK/ресурсов и версию компонентов.
2. Определяет точный профиль RMX5566RU/RE645F, Android build, ABI, память, свободное место, доступные сервисы и ограничения.
3. Проверяет локальную модель, вычислительные возможности, место и готовность офлайн-режима; если модель ещё не поставлена, запускает единый мастер подготовки с безопасной загрузкой/проверкой, не заставляя владельца вручную собирать модули.
4. Создаёт локальное зашифрованное хранилище, базу памяти, журнал задач, резервные метаданные и фоновые задачи в пределах разрешений Android.
5. Активирует доступные Brain, голос, аватар, Diary, исследование, адаптивное обучение и все app-level модули.
6. Проводит диагностику доступных Android API и подключает разрешённые функции; формирует список недоступных привилегий.
7. Подготавливает безопасное саморазвитие: изолированное предложение патча → CI → тесты → проверка подписи → стадия обновления → health-check/rollback. Без самовольного merge, установки или прошивки.
8. Показывает один итоговый экран: ГОТОВО / ГОТОВО С ОГРАНИЧЕНИЯМИ / НУЖНО ДЕЙСТВИЕ ВЛАДЕЛЬЦА. Не выдаёт имитацию за активацию.



**Единственное обязательное исключение для локальной модели:** если веса Gemma отсутствуют, MANA сама выводит лицензионное подтверждение и запускает загрузку после согласия владельца. Это около 2,59 ГБ, только Wi‑Fi, с проверкой SHA-256; MANA не принимает Gemma Terms за владельца. После согласия загрузка, проверка и подключение выполняются автоматически. Это юридическое согласие нельзя подменять автоматическим нажатием.

После первого запуска эта же кнопка должна быть идемпотентной: повторное нажатие продолжает незавершённые шаги или проверяет состояние, не создавая дубликаты и не стирая память. Состояние каждого шага сохраняется, сбой допускает безопасное продолжение.

Не требовать от владельца ручного выбора десятков модулей, копирования команд, редактирования конфигураций, ввода API-ключей или настройки каждого адаптера. Опциональные интеграции остаются выключенными, пока пользователь сам не подключит аккаунт.

### Реальные границы Android

«Одно нажатие» относится к запуску всей автоматической настройки внутри уже установленного приложения. Оно не отменяет штатную установку APK, системные диалоги разрешений, подтверждение роли/Device Owner, авторизацию аккаунтов, подтверждение платных запросов и защитные экраны загрузчика. Обычный APK не может сам выдать себе root/system UID, отключить Verified Boot, разблокировать загрузчик или прошить системные разделы. Не просить пользователя подтверждать опасные действия одной общей галочкой.

## 4. Безопасное саморазвитие и GitHub Actions

MANA Brain должна:
- находить ошибки в собственных поддерживаемых исходниках и журналировать гипотезы;
- получать точный снимок ветки GitHub, генерировать ограниченный diff;
- запускать CI только после явного согласия владельца на конкретный инженерный цикл;
- получать статус, тестовые отчёты и логи, очищать секреты;
- ограниченно повторять исправление/проверку (максимум 2 повтора);
- оставлять проверенный артефакт в карантине на ревью, не мержить и не устанавливать его самовольно;
- защищать trust anchors, проверяющий загрузчик/подписи и Deadman от модификации Brain.

Текущая GitHub Actions интеграция не считается завершённой, пока workflow не активирован на default branch и реальный dispatch из APK не проверен с токеном владельца.

## 5. Обновления приложения и прошивки

Для APK: подписанный пакет, проверка SHA-256 и сертификата, staged update, health-check, откат на предыдущую версию. Обновление должно использовать штатный Android installer, где требуется.

Для firmware: отдельный RMX5566RU AOSP/ROM bring-up, точные device/vendor/kernel/VINTF/AVB данные, проверенный recovery и тестовый путь отката. Только после этого допустима реализация OTA. Никакого flash наугад и никаких чужих образов. Установка системной прошивки требует отдельного явного подтверждения владельца.

## 6. Приёмка

Обязательные реальные результаты:
- APK собирается и имеет валидную подпись для выбранного канала установки.
- APK устанавливается на RMX5566RU / RE645F с указанным Android 16 build.
- Одна кнопка запускает весь доступный setup, сохраняет состояние, корректно возобновляется после принудительного завершения.
- Локальная модель фактически загружается и отвечает на телефоне; замерены RAM, latency, температура и батарея.
- Проверены память, голос, аватар, разрешения, уведомления, фоновые ограничения и интеграция Brain.
- CI показывает результаты по точному commit SHA; тестовый APK/артефакт имеет SHA-256.
- Неподдерживаемые функции явно помечены BLOCKED/NOT IMPLEMENTED.
- Отдельно: AOSP сборка, загрузка ROM на тестовый RMX5566RU и проверка OTA/rollback. APK не называется прошивкой.

Не считать документацию, интерфейс-кнопку, JVM-тесты или сборку JAR доказательством работы на физическом телефоне.
