# MANA ASI — универсальная архитектура и контракт установки одним действием

Статус: проектная спецификация; не утверждает, что универсальный установщик или прошивка уже реализованы.

## 1. Основное назначение

MANA ASI (Autonomous System Intelligence) — основная архитектура MANA Genesis 4.0. Она сохраняет ранее согласованные подсистемы и строит единую систему вокруг MANA Brain: локальный интеллект, память, голос, аватар, исследование, инженерные инструменты, управление доступными функциями Android и подготовка системной интеграции.

**Универсальность — обязательная цель продукта.** realme RMX5566RU / RE645F — первый контрольный тестовый аппарат владельца, но архитектура, установщик и матрица совместимости не должны быть привязаны к нему.

## 2. Целевой охват устройств

- Минимальная версия: Android 12 / API 31.
- Обязательные семейства для проверки: Samsung, Xiaomi/Redmi, realme, Huawei, Honor, Meizu, Fly.
- Другие Android OEM — расширяемая матрица.
- Архитектуры CPU, объём памяти, ABI, экран, доступность сервисов Google и OEM-ограничения определяются динамически.
- Нельзя объявлять производителя или модель совместимыми только по названию бренда: совместимость подтверждается тестами на конкретных версиях ОС и прошивок.

## 3. Универсальная многослойная реализация

### Layer A — portable Android application (API 31+)
Единый APK: MANA Brain UI, локальное хранилище, голосовой интерфейс, аватар, настройки, диагностика, доступные интеграции и управление функциями через публичные Android API. Базовые функции должны работать без root и без системной подписи.

### Layer B — capability adapters
Набор адаптеров по возможностям и версиям API, а не жёсткая ветка «один бренд — один взлом». Каждый адаптер сообщает: обнаружено, доступно, требуется разрешение, ограничено OEM, неподдерживаемо или не проверено. Отсутствие API не маскируется.

### Layer C — optional privileged integration
Для функций, требующих системной подписи, Device Owner, специальных ролей, root или привилегированной службы, готовится отдельный документированный путь с явной авторизацией владельца и проверкой совместимости. Никакого скрытого получения привилегий, эксплуатации уязвимостей, обхода защитных механизмов или самораспространения.

### Layer D — device-specific OS port
Полная замена/модификация ОС возможна только как отдельная сборка для точного устройства: device tree, ядро, vendor blobs, HAL/VINTF, AVB/подписи, разметка разделов, загрузчик и проверенный способ восстановления. Универсальный APK не является универсальной прошивкой.

## 4. Требование «одна кнопка»

Целевой пользовательский сценарий:
1. Пользователь получает один подписанный пакет из доверенного канала.
2. Запускает штатный Android installer и подтверждает установку приложения.
3. При первом запуске MANA автоматически определяет устройство, ABI, API level, OEM, доступные API, память и ограничения.
4. Установщик выполняет безопасную настройку доступных функций, проверку целостности компонентов, подготовку локального хранилища и формирование отчёта.
5. Все необязательные компоненты загружаются только из подписанных источников, проверяются по хешам/подписям и устанавливаются в область приложения.
6. MANA предлагает включить только те системные роли и специальные разрешения, которые действительно нужны; пользователь подтверждает их в системных экранах Android.
7. Приложение может предложить перезагрузку, если она действительно нужна и поддерживается сценарием.

**Граница платформы:** обычное приложение Android не может гарантированно скрыть системные подтверждения, само выдать себе runtime/special permissions, назначить себя Device Owner, получить root, отключить Verified Boot или молча прошить разделы. Поэтому «одна кнопка и полностью изменённая ОС на любом телефоне» не является реализуемым универсальным контрактом для обычного APK. Цель one-action относится к установке и настройке доступного приложения; системный порт имеет отдельные OEM-зависимые условия.

## 5. Безопасность и доверие

- MANA Deadman располагается вне полномочий MANA Brain и блокирует запуск Brain/его фоновых задач до ручного восстановления владельцем.
- Обновления: подписанные артефакты, проверка хеша, staged rollout, тесты, откат.
- Саморазвитие: предложение патча → изолированная сборка → тесты → просмотр владельцем → подписанное обновление. Brain не может менять Deadman, trust anchors или механизм проверки подписи.
- Финансовые действия, сообщения, звонки, удаление данных, смена системных настроек с последствиями и прошивка требуют отдельного подтверждения.
- Не реализовывать malware, exploit chains, stealth persistence, privilege escalation, защитный bypass, заражение или распространение.

## 6. Обязательные проверки

Матрица должна включать реальные устройства/эмуляторы для API 31/32, 33, 34, 35 и 36; OEM-прошивки Samsung One UI, Xiaomi HyperOS/MIUI, realme UI, Huawei EMUI/HarmonyOS Android-совместимые варианты, Honor MagicOS, Meizu Flyme и Fly. Отдельно проверять установку/обновление/удаление, фоновые ограничения, энергосбережение, голос, overlay, Bluetooth, уведомления, локальную модель, восстановление после сбоя и Deadman.

Результат по каждой модели: PASS / PASS_WITH_LIMITATIONS / BLOCKED / NOT_TESTED. Не использовать «работает на любом Android» до завершения матрицы.

## 7. Первый контрольный аппарат

realme RMX5566RU / RE645F (Android 16, API 36, Qualcomm SM6225, ARM64, locked bootloader, green Verified Boot) — первый аппарат для фактической проверки portable APK и device profiler. Это не ограничивает универсальную архитектуру и не даёт права считать другие OEM совместимыми без тестирования.

Для этого устройства запрещено выбирать прошивку C85 5G/Dimensity 6300: фактический профиль указывает Snapdragon 685/SM6225. До появления точных исходников и проверенного восстановления прошивка не собирается и не прошивается.

## 8. Критерии готовности

- Единый portable APK с minSdk 31 собирается и проходит тесты.
- Автоматический профиль устройства создаётся на API 31+ без root.
- Capability adapters корректно сообщают ограничения.
- One-action app installation не обещает обход штатного Android installer.
- Никаких скрытых системных изменений или несанкционированных повышений привилегий.
- Для каждой модели заявляется только фактически проверенный уровень совместимости.
