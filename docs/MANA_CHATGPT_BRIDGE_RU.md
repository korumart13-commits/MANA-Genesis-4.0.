# MANA ChatGPT Bridge — диагностический канал

**Цель:** передавать ChatGPT проверяемые сведения о фактическом состоянии установленной MANA, чтобы анализировать пробелы, ошибки и результаты тестирования. Это не обещание прямого доступа к текущему диалогу ChatGPT.

## Каналы

1. **OpenAI API connector (отдельный, необязательный):** MANA может обращаться к доступной модели OpenAI через официальный API. Пользователь сам добавляет API key в Android Keystore-backed storage; ключ не встраивается в APK, не попадает в логи, отчёты, экспорт или Git. API доступ, биллинг и модели зависят от отдельного аккаунта и доступности API.
2. **ChatGPT diagnostic handoff (основной для обратной связи в этот чат):** MANA формирует локальный JSON + читаемый Markdown-отчёт. Пользователь отправляет его в ChatGPT через Android Sharesheet или прикрепляет к беседе. Нельзя заявлять, что стороннее приложение может само записать сообщение в уже открытый ChatGPT conversation или читать его историю.
3. **Optional secure backend relay:** только если позднее будет реализован отдельный сервер с аутентификацией, явным согласием пользователя, ограничением данных и документированным endpoint. Не является частью MVP и не должен быть имитирован.

## Диагностический пакет

Версионированная схема `mana-diagnostic-report/v1` включает:
- timestamp UTC, MANA app/build/version, commit SHA и build flavor;
- device model (если пользователь согласен), Android API level, ABI, доступная память/хранилище в агрегированном виде;
- статусы модулей: Brain, local inference/runtime/model, encrypted memory/RAG, voice, avatar, launcher/UI, adaptive learning, Diary, Future Updates, receptionist, contacts, Life Manager, Yandex/VK, game integrations, wearables/vehicle, updates;
- для каждого модуля: `IMPLEMENTED`, `PARTIAL`, `NOT_IMPLEMENTED`, `BLOCKED`, `NEEDS_DEVICE_TEST`; проверка, дата, результат, причина/ошибка, evidence/test id;
- Android permissions/roles: granted/denied/not requested, без содержимого пользовательских данных;
- локальные тесты и последние CI identifiers/statuses, если они доступны;
- список известных ограничений и рекомендуемый следующий шаг.

Каждый статус должен быть подтверждён runtime probe или тестом. Наличие класса, экрана, TODO, stub или декларации зависимости не означает, что функция работает. Не маркировать функцию `IMPLEMENTED` без проверяемого теста.

## Privacy and security
- По умолчанию локальная генерация отчёта; отправка только по явному действию владельца.
- Исключить API keys, access/refresh tokens, пароли, Android ID, телефонные номера, контакты, SMS, звонки, содержимое уведомлений, личные файлы, переписку и точную геолокацию.
- Санитизировать stack traces, URL query parameters, headers и свободный текст; не экспортировать секреты даже в debug режиме.
- Пользовательский предпросмотр, список категорий, кнопки «Экспортировать» и «Поделиться», возможность удалить отчёт.
- Шифрование при хранении; безопасная передача; TLS; минимальные разрешения; audit log без секретов.
- Если экспорт содержит персональные данные, требовать отдельное явное согласие и объяснять зачем.

## Android UX
На странице MANA > Диагностика:
- «Проверить MANA» — запускает доступные локальные self-tests;
- сводка «Работает / Частично / Не работает / Не проверено»;
- «Сформировать отчёт» — генерирует JSON и Markdown;
- «Поделиться с ChatGPT» — вызывает Android Sharesheet с Markdown/JSON или URI файла через FileProvider;
- «Скопировать краткий отчёт».
Не открывать ChatGPT автоматически и не утверждать, что файл доставлен, пока пользователь сам не завершил отправку.

## Acceptance criteria
1. Unit tests для сериализации схемы и статусов.
2. Tests на redaction: токены, ключи, пароли, PII не попадают в экспорт.
3. Tests на пустые/недоступные модули и корректное отображение `NOT_IMPLEMENTED` / `BLOCKED`.
4. Instrumentation test для создания файла и Android Sharesheet/FileProvider.
5. Проверка на API 29, 33, 36; физический RMX5566 test остаётся `NEEDS_DEVICE_TEST` до проверки на устройстве.
6. Документация должна честно различать OpenAI API и передачу отчёта в текущий ChatGPT чат.

## Ограничения
Этот документ задаёт архитектуру и критерии. Он сам по себе не реализует Android UI, API client, runtime probes, upload backend или интеграцию с ChatGPT app. Не объявлять мост готовым, пока код, тесты, CI и device verification не подтверждены.
