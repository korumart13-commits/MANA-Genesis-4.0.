# MANA XZ — игровой пакет «Живая квартира»

Отдельный исходный проект Godot 4.x для игрового представления Маны. Использует те же glTF-файлы персонажа, что и Android-лаунчер, без создания второй личности.

## Файлы
- `project.godot` — проект 3D-игры.
- `scenes/mana_apartment.tscn` — главная сцена.
- `scripts/mana_apartment.gd` — процедурная спальня и гостиная: кровать с металлическим каркасом, шкаф, диван, ТВ, компьютер, окно и свет.
- `scripts/mana_companion.gd` — перемещение по квартире, настроение и самостоятельный выбор наряда.
- `scripts/mana_voice_bridge.gd` — контракт подключения к нативному голосу.
- `assets/characters/` — общие glTF-ресурсы MANA из Android-проекта.

## Запуск
Открой папку `game/mana-xz-world` в Godot 4.x и запусти главную сцену.

## Важные границы
Это игровой исходный пакет; он ещё не встроен в Android APK и не заменяет SceneView-рендерер лаунчера. Квартира собрана из процедурных блоков, а не из финальных текстур. Движение использует безопасные точки, пока без запечённой navmesh. Доступные glTF-клипы: Idle, Speaking, Happy, Playful; отдельного Walk-клипа и полноценного facial blendshape rig нет. Голос приложения использует установленный Android TextToSpeech-движок: выбранный русский голос зависит от доступных на телефоне голосовых данных. Отдельная аудиозапись/облачный голосовой пакет не включён.
