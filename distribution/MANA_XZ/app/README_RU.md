# Android APK

Готовый APK должен быть получен из Android Gradle build и подписан ключом выпуска. APK не хранится здесь как фиктивный файл. На этапе сборки проверять package id, versionCode/versionName, ARM64 ABI, min/target SDK, разрешения, подпись и совместимость RMX5566. До успешной сборки и установки на устройстве не маркировать пакет как готовый релиз.

Ожидаемый результат CI: debug APK для тестов. Релизный APK должен быть подписан отдельным стабильным ключом владельца; debug APK не является обновляемым релизом.
