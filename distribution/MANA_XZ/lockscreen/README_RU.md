# Живые обои экрана блокировки

Цель — живой, регулярно меняющийся экран блокировки МАНЫ. Генератор создаёт/обновляет изображение, планировщик применяет его через Android WallpaperManager только к FLAG_LOCK. Не изменять FLAG_SYSTEM (рабочий стол). Для настоящей непрерывной анимации нужен Android WallpaperService и отдельная проверка ограничений realme/Android 16. Автоматическая генерация должна работать локально либо через разрешённый сервис; сетевые генерации требуют согласия и интернета. Текущий процедурный рендерер — не diffusion и не 3D-рендер.
