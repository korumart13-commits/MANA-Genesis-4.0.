# MANA Brain runtime

Единый MANA Brain: локальный inference backend, маршрутизатор моделей, контекст, планировщик задач, инструменты Android и шлюз интернет-источников. При отсутствии сети работает локальный режим. Облачные GPT/Claude/Gemini/Grok подключаются опционально по пользовательским ключам. Не включать секреты в дистрибутив.

Саморазвитие: исследование → источники → проверка → локальная заметка/навык → тесты в изоляции → предложение обновления → подтверждение владельца → установка → контроль и откат.
