# Модули

Каждый модуль должен иметь собственный manifest с id, версией, зависимостями, minSdk, разрешениями, SHA-256, подписью, размером и инструкцией восстановления. Установка транзакционная, в приватный каталог приложения, с проверкой зависимостей и откатом. Модуль не получает root или системные права только из-за нахождения в этой папке.
