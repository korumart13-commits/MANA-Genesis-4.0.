# Дизайн-система MANA XZ — Ω

Единая визуальная система для Android-приложения, будущей MANA OS и экранов настройки.

## Палитра

- Фон: `#071426`
- Поверхность: `#102B50`
- Основной синий: `#1765A8`
- Акцент: `#54C8F5`
- Текст: `#EAF4FF`
- Вторичный текст: `#91A9C5`

## UX-направление

Android-first, индивидуальный интерфейс MANA без копирования фирменного интерфейса Apple или других ассистентов. Предпочтительная навигация: «Главная / Чат / Модули / Приложения». Один центральный MANA Brain и одна личность. Плавающий 3D-аватар остаётся опциональным и не должен перекрывать поле ввода или системную навигацию.

Карточки модулей показывают реальный статус: готово, требует разрешения, не подключено или в разработке. Недоступные функции не должны изображаться работающими.

## Доступность

Минимальная интерактивная зона 48dp, поддержка увеличенного текста и TalkBack, контрастные подписи, важные действия не только через жесты. Подробный UX-документ находится в `docs/MANA_XZ_MOBILE_UX_RESEARCH_AND_DESIGN_RU.md`.

## Статус

Это целевая дизайн-система и reference tokens. Полный переход всех старых экранов на единый Material 3 layout ещё не завершён; не выдавать документ за полностью реализованный интерфейс.
