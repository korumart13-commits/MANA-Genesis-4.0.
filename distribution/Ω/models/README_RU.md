# Локальная модель MANA

Основная локальная модель комплекта — Gemma 4 E2B IT в формате LiteRT-LM.

- Файл: `models/Gemma/gemma-4-E2B-it.litertlm`
- Размер: 2 588 147 712 байт.
- SHA-256: `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c`
- Runtime: LiteRT-LM Android 0.16.1, встроен в APK.
- Backend: GPU с переходом на CPU при ошибке инициализации.

После установки APK владелец один раз выбирает файл модели в Android file picker. MANA проверяет точный размер и SHA-256, копирует модель в приватное хранилище и подключает локальный движок. После успешного импорта базовый диалог доступен офлайн.

MANA Resource Governor использует консервативный порог около **3 548 MB доступной физической RAM** для модели этого размера. Это внутренняя оценка безопасности приложения, не официальное минимальное требование Gemma. Реальное потребление зависит от backend, контекста и прошивки; производительность на Snapdragon 685 / RMX5566 ещё нужно измерить. Указанные владельцем 16 GB динамического расширения не считаются физической RAM.

Не переименовывать `.litertlm` в GGUF. Экспериментальный llama.cpp backend — отдельная ветка и не является основным runtime этого APK.
