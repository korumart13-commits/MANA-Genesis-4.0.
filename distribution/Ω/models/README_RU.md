# Локальные модели

Здесь размещаются только проверенные модели с известной лицензией и контрольными суммами. Модельный файл может быть большим и не включается в Git. Для каждой модели требуется manifest: имя, версия, формат, архитектура, SHA-256, источник, лицензия, размер, требования RAM и поддерживаемый runtime. Не переименовывать форматы моделей (например, LiteRT-LM в GGUF). До теста на Snapdragon 685 не заявлять производительность.
