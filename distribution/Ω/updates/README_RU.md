# Обновления

Здесь хранится только описание канала обновлений и схема пакетов. Каждый реальный пакет обязан иметь подпись, SHA-256, версию, совместимость устройства, зависимости и план отката. APK обновляется через Android PackageInstaller с подтверждением владельца. Не устанавливать код из непроверенных интернет-источников.
