# MANA Genesis 4.0 — Константа Омега

## Что это

**Константа Омега** — единая корневая папка всей системы MANA. Она устроена по принципу каталога компьютерной игры: есть стартовое приложение, файл входа/подключения, движок, данные, ресурсы, игровые проекты, конфигурация, обновления, журналы и полный исходный проект.

Главный файл подключения — `MANA_OMEGA_ENTRY.json`. Он описывает, где лежат компоненты и какой Android APK является точкой запуска. Корневой манифест не является исполняемым файлом: Android запускает APK, а манифест служит картой комплекта и контрактом для проверяющего установщика.

## Корневая структура

```text
Константа_Омега/
├── MANA_OMEGA_ENTRY.json       # центральный файл подключения и карта компонентов
├── MANA_OMEGA.json             # сведения о сборке и целевом устройстве
├── SHA256SUMS.txt              # контрольные суммы файлов
├── BUILD_REPORT_RU.txt         # отчёт CI-сборки и ограничения
├── Launcher/
│   └── INSTALL_MANA_XZ.apk     # Android-точка входа MANA
├── Engine/
│   ├── Brain/                  # собранные/исходные компоненты MANA Brain
│   ├── Inference/              # LiteRT-LM и локальная модель
│   └── Runtime/                # системные runtime-компоненты
├── Source/
│   └── Project/                # полный отслеживаемый исходный проект на commit сборки
├── Data/
│   ├── Memory/
│   ├── Knowledge/
│   ├── Diary/
│   └── Saves/
├── Assets/
│   ├── Avatar/
│   ├── Textures/
│   ├── Materials/
│   └── UI/
├── Audio/Voice/ru-RU/
├── Worlds/MANA-Living-World/
├── Games/Minecraft-Bedrock/
├── Modules/
├── Config/
├── Updates/
├── Logs/
├── Docs/
└── Firmware/AOSP/              # исходники будущей прошивки, НЕ flashable ROM
```

## Как используется

1. Пользователь распаковывает один архив и получает одну центральную папку.
2. Устанавливает `Launcher/INSTALL_MANA_XZ.apk`.
3. Android запускает MANA через APK; APK не может быть заменён одним JSON-файлом.
4. Для локального ИИ пользователь выбирает файл Gemma в системном Android-пикере; MANA проверяет размер и SHA-256 и копирует модель в приватное хранилище.
5. `MANA_OMEGA_ENTRY.json` и `SHA256SUMS.txt` задают карту компонентов и проверку целостности.
6. Полный каталог `Source/Project/` сохраняет исходники MANA на том же commit, из которого собран комплект.

## Важное техническое состояние

Сейчас APK умеет запускаться как Android-приложение и импортировать локальную модель через SAF. Автоматическое подключение всех папок как динамических модулей пока не реализовано. Android не разрешает APK произвольно исполнять исходники из общей папки; для расширений нужны отдельный безопасный формат пакетов, подписи, проверка совместимости и явное подтверждение пользователя. Неисполняемые ресурсы можно подключать через разрешённый Android-доступ к файлам.

Папка `Firmware/AOSP/` — только исходники/заготовки будущей системной прошивки. Не прошивать её и не копировать в системные разделы. Полноценная ROM для RMX5566 пока не собрана.
