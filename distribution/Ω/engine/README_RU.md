# MANA Brain — локальный движок Ω

Это центральный мозг единой MANA. Приложение не должно зависеть от облака для базового диалога.

## Основной локальный стек

- Android runtime: LiteRT-LM 0.16.1.
- Модель комплекта: Gemma 4 E2B IT в формате `.litertlm`.
- Файл в полном архиве: `models/Gemma/gemma-4-E2B-it.litertlm`.
- SHA-256: `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c`.
- Запуск: GPU backend с переходом на CPU, если GPU инициализация не удалась.
- Импорт: владелец подтверждает лицензию и выбирает модель штатным Android file picker; MANA копирует файл в приватное хранилище и проверяет полный SHA-256.
- После успешного импорта MANA может отвечать локально без интернета.

## Исходники

В полном Ω комплекте рядом находятся `engine/mana-brain/` и `engine/os-core/`; полный исходный проект также находится в `source/MANA-XZ-source-project.zip`.

`os/native/llama-jni` — дополнительная экспериментальная ветка для GGUF/llama.cpp. Она не считается включённым и рабочим Android backend, пока отдельная ARM64 сборка не встроена в APK и не протестирована. Основной комплект опирается на LiteRT-LM.

## Ограничения

Наличие движка и весов не доказывает скорость или стабильность на realme C85 4G / RMX5566. До реального теста неизвестны точная скорость генерации, RAM пик, нагрев и расход батареи. Если модель не установлена или не может загрузиться, MANA должна честно показывать это, а не имитировать ответ.
