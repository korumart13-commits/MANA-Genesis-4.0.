# 3D-аватар МАНЫ

Сюда помещаются оригинальная модель, материалы, риг, анимации, эмоции, окружение квартиры и метаданные версий. Сохранять единый внешний вид, голос и личность аватара в приложении и оболочке. Не извлекать игровые модели третьих лиц. Существующую концепцию всплывающего аватара не менять без отдельного запроса.
