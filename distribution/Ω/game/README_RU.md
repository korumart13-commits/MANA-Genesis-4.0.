# Игровые компоненты MANA XZ — Ω

В этом разделе полного комплекта находятся игровые исходники MANA:
- `mana-xz-world/` — Godot-проект «Живая квартира» с общей моделью МАНЫ, сменой настроения и одежды.
- `minecraft-bedrock/` — исходники Bedrock companion/bridge pack.

Игровые компоненты не являются отдельной личностью или отдельным ИИ: они должны обращаться к тому же MANA Brain. Сейчас Godot world — самостоятельный исходный проект, а не встроенный экран Android APK. Совместимость с конкретной версией Minecraft и Android runtime требует отдельного теста.
