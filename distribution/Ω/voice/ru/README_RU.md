# Русский офлайн-голос МАНЫ

Предусмотрен нейросетевой русский голос Piper. В комплекте должны находиться совместимые on-device runtime и веса голоса, лицензия и SHA-256 manifest. Не подменять отсутствие весов системным онлайн TTS. Голосовые бинарные файлы добавляются только после проверки лицензии, размера, ARM64 совместимости и теста на целевом телефоне.
