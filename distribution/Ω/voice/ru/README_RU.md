# Русский офлайн-голос МАНЫ

Основной голос — Piper VITS `ru_RU-irina-medium` (русский женский голос). Голос синтезируется на устройстве через sherpa-onnx; интернет для произнесения текста не нужен.

## Комплектация Ω

- Gradle получает архив `vits-piper-ru_RU-irina-medium.tar.bz2` из релиза sherpa-onnx.
- Архив проверяется по закреплённому SHA-256: `1fc0f54e5e084fe287c07909f2f6e0ba6d857864cf800e3ab80286a4e8233008`.
- При успешной Android-сборке файлы модели, tokens и eSpeak NG data включаются в APK как assets.
- Полный Ω ZIP дополнительно копирует эти ресурсы в `voice/ru/` для прозрачной комплектации.
- Лицензия исходного Piper voice указана upstream как MIT; источник: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium

## Проверка

Наличие этого README не означает, что голос уже установлен в системный раздел Android. Обычный APK хранит голос внутри своих ресурсов и приватного каталога. Системная интеграция возможна только на отдельном этапе AOSP/ROM.

До успешной сборки и запуска на RMX5566 голос помечается как «ресурсы включены в APK / аппаратная проверка ожидается». При ошибке загрузки или проверки нельзя подменять его онлайн TTS и показывать ложный статус «готов».
