# MANA Genesis 4.0 Bootstrapper (первый исполняемый этап)

**Назначение:** один стартовый скрипт для RMX5566RU/RE645F. На телефоне он выполняет только безопасный сбор доступных сведений и создаёт отчёт. На Linux-хосте он проверяет комплектность исходников и окружения перед AOSP/ROM-сборкой.

## Запуск на телефоне (Termux)

1. Установите Termux из официального источника и Python 3: `pkg install python`.
2. Скопируйте папку bootstrapper в память телефона.
3. Выполните:
   ```sh
   chmod +x bootstrap.sh
   ./bootstrap.sh audit
   ```
4. Отчёт появится в `out/device-audit.json`. Скрипт не требует root и не записывает разделы устройства.

Если есть ADB с компьютера, можно дополнительно выполнить `adb devices` и `adb shell getprop` самостоятельно; bootstrapper не включает скрытое управление устройством.

## Проверка готовности сборки на Linux

Подготовьте рабочие каталоги и запустите:
```sh
export MANA_AOSP_DIR=/path/to/aosp
export MANA_DEVICE_TREE=/path/to/device-tree
export MANA_KERNEL_DIR=/path/to/kernel
export MANA_VENDOR_DIR=/path/to/vendor
./bootstrap.sh readiness
```
Скрипт проверит наличие каталогов, инструментов, объём свободного места и критические входные файлы. Отсутствующее или неизвестное будет помечено явно. Это не гарантирует совместимость исходников.

## Важные ограничения и защита

- Никакого root, разблокировки загрузчика, обхода AVB, записи разделов или автоматической прошивки.
- Никаких выдуманных значений: статусы только `VERIFIED`, `MISSING`, `UNKNOWN`, `BLOCKED`.
- Закрытые Realme vendor blobs/firmware не извлекаются и не скачиваются без законного источника и проверки происхождения.
- ROM build не запускается автоматически в этой первой версии. Сначала требуется независимая проверка device tree, kernel, vendor, VINTF/HAL, partition layout, AVB и лицензий.
- AI-провайдеры (OpenAI, Gemini, Claude, Grok и другие) могут подключаться отдельным модулем позднее. Ключи API не сохраняются в репозитории и не встраиваются в APK.
- В целевой сборке запрещены встроенная звонилка, набор номера и call UI.

## Состояние этапа

Это **Bootstrapper v0.1 (audit + readiness gate)**, а не готовая прошивка и не полноценный автоматический ROM-компилятор. Для реальной сборки RMX5566RU ещё необходимы проверенные OEM-совместимые исходники и Linux build host.
