# MANA One-Tap Update — безопасный установочный пакет

## Назначение
Единый пакет обновления MANA для RMX5566RU. Пользователь запускает пакет вручную; пакет проверяет устройство и целостность содержимого, показывает состав изменений и передаёт установку штатному Android/Realme механизму, если формат и подпись поддерживаются.

## Важные ограничения
- Это НЕ вирус, эксплойт, root-инструмент или обход защиты.
- Запрещены скрытая установка, автозапуск без согласия, повышение привилегий, обход Package Installer/Recovery/AVB, отключение SELinux и изменение системных разделов без корректной подписи.
- Обычный APK не может самостоятельно заменить системные компоненты Realme или превратиться в OTA.
- Настоящий OTA для обновления через настройки Realme требует совместимого формата, точной базы прошивки, корректных метаданных и подписи, принимаемой устройством.
- Не включать драйверы, ядро, vendor/HAL, firmware или SELinux policy, пока не подтверждены точные исходники и соответствие RMX5566RU.

## Сценарий одного нажатия
1. Проверить модель RMX5566RU, Android API 36, fingerprint и текущую сборку.
2. Проверить SHA-256 всех вложений и подпись манифеста.
3. Проверить свободное место, питание и доступность резервного восстановления.
4. Показать понятный список изменений и несовместимостей.
5. Если содержимое — APK, открыть системный Package Installer и запросить подтверждение пользователя.
6. Если содержимое — легальный OTA, передать его только штатному механизму обновления, который проверяет подпись и совместимость.
7. Записать результат в журнал; при ошибке прекратить установку без изменения системы.

## Состав будущего пакета
- manifest.json — версия, целевая модель, базовая сборка, перечень файлов и SHA-256.
- checksums.txt — контрольные суммы.
- assets/bootanimation.zip — только Android userspace boot animation.
- assets/mana-lockscreen-wallpaper.png — графический ресурс.
- app/ — отдельное приложение MANA, если оно собрано и подписано.
- system-bridge/ — только исходники/конфигурация проверенной службы; установка требует платформенной сборки и допустимой подписи.
- ota/ — зарезервировано; не заполнять фиктивным ZIP до появления совместимого подписанного OTA.

## Условия выпуска
Пакет нельзя называть «обновлением Realme» и нельзя публиковать как устанавливаемый OTA, пока не пройдены проверки:
- точная заводская база RMX5566RU RMX5566_16.0.5.1310(EX01) либо документированно совместимая версия;
- подтверждённые partition map, payload/OTA format и update engine expectations;
- проверенная подпись, которую принимает штатный механизм;
- успешная проверка на тестовой сборке и проверенный путь восстановления;
- сохранение пользовательских данных, OEM-компонентов, AVB и SELinux enforcing.

**Текущий статус:** спецификация безопасного установщика. Готового APK, OTA ZIP или системного моста этот документ не создаёт и не подменяет.
