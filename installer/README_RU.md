# MANA Genesis 4.0 — пакет предварительной проверки RMX5566RU

**Назначение:** безопасная read-only диагностика перед будущей сборкой и установкой настоящей прошивки MANA.

## Что входит
- `MANA_RMX5566RU_PREFLIGHT.sh` — собирает системные свойства Android и проверяет заявленный профиль RMX5566RU / RE645F.
- `tests/preflight_test.sh` — автоматические тесты положительного и отрицательных сценариев.
- GitHub Actions workflow — проверяет синтаксис Bash, ShellCheck и тесты, затем собирает ZIP-артефакт.

## Запуск на телефоне
Скопируйте скрипт на телефон, откройте Termux и выполните:

```sh
bash MANA_RMX5566RU_PREFLIGHT.sh
```

Отчёт будет сохранён в домашнюю папку Termux. Скрипт не требует root и не читает пользовательские файлы, IMEI, контакты или содержимое разделов.

## Чего пакет НЕ делает
Это не прошивка, не APK-инсталлятор и не SystemUI. Он не меняет загрузчик, не получает root, не записывает разделы, не выключает Verified Boot и не перезагружает телефон. Он не может заменить Realme UI или изменить заставку загрузки.

Причина: на целевом профиле загрузчик ранее сообщал locked, а Verified Boot — green. По требованиям Android, изменение защищённых разделов возможно только после явной разблокировки загрузчика и корректной цепочки доверия. A/B и dynamic partitions требуют точной реализации boot-control, VINTF, AVB и метаданных разделов.

## Блокирующие условия настоящей прошивки
До появления полного и проверенного набора для точной ревизии RMX5566RU / RE645F нельзя создавать flashable ZIP/IMG:
- точный Android 16 device tree;
- совместимые kernel sources/config и DTB/DTBO;
- точные vendor/ODM blobs, HAL и VINTF;
- vendor_boot/init_boot и firmware modules;
- partition metadata и A/B layout;
- проверенная AVB signing chain;
- полный stock restore package и испытанный rollback;
- аппаратные тесты на реальном устройстве.

Не подменять эти файлы исходниками похожей модели или другим выпуском C85. Успешный CI — проверка пакета и тестов, но не доказательство загрузки ROM на телефоне.
