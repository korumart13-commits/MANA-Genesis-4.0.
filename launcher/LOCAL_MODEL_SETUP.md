# MANA XZ (MANA Genesis 4.0) — локальная модель

## Что подключено в Android-прототипе

- LiteRT-LM Android 0.16.1.
- Локальная модель имеет приоритет; GPU backend пробуется первым, затем runtime пытается загрузить CPU backend.
- Модель хранится отдельно от APK в приватном каталоге приложения.
- Импорт ограничен 16 ГБ, проверяет свободное место, считает SHA-256, пишет во временный файл и атомарно заменяет установленную модель.
- Облачный резерв OpenAI / Anthropic / Gemini / xAI выключен по умолчанию. Ключи хранятся в AES-GCM с ключом Android Keystore. Каждый облачный запрос требует отдельного подтверждения; контекст локальной памяти не передаётся в облако.

Официальный Android API: https://developers.google.com/edge/litert-lm/android

## Кандидат для realme C85 4G / RMX5566

Gemma 4 E2B IT в формате LiteRT-LM:
- Репозиторий: https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm
- Файл: gemma-4-E2B-it.litertlm
- Размер: около 2.59 GB на диске.
- Опубликованный SHA-256: 181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c.
- Gemma 4 распространяется по Apache License 2.0. Копия лицензии и NOTICE включены в установочный ZIP: `models/Gemma/LICENSE-APACHE-2.0.txt` и `models/Gemma/NOTICE.txt`.

Это кандидат, а не подтверждённая производительность на realme C85 4G / RMX5566. Публичные измерения карточки модели получены на других устройствах и не переносятся на SM6225. Для телефона нужно измерить загрузку, RAM, скорость генерации, нагрев и расход батареи. Не выбирай варианты Google Tensor / Tensor G5/G6 или специализированные NPU для другого устройства: на realme C85 4G / RMX5566 Qualcomm SM6225.

## Более лёгкий резервный вариант

Для первого запуска и проверки совместимости можно использовать LiteRT Community Gemma 3 1B IT, если доступный .litertlm артефакт совместим с текущей версией LiteRT-LM. Он меньше, но слабее. Сравнение моделей и скорость на телефоне ещё предстоит проверить.

## Подключение в сценарии «одно нажатие»

1. Полностью распакуй единый ZIP; внутри уже находится `models/Gemma/gemma-4-E2B-it.litertlm`.
2. Установи `installer/INSTALL_MANA_XZ.apk` штатным установщиком Android, открой MANA и нажми основную кнопку «УСТАНОВИТЬ MANA XZ».
3. Ознакомься с Apache License 2.0 в комплекте. В системном окне выбора Android укажи файл Gemma из распакованной папки.
4. MANA копирует файл в приватное хранилище, проверяет точный размер и SHA-256, затем подключает его к LiteRT-LM. Если файла комплекта нет, можно выбрать автоматическую загрузку по Wi-Fi.
5. Команды Termux и самостоятельная сборка не нужны. Системное окно выбора файла остаётся штатным требованием Android.

Ручной импорт через «Выбрать локальную модель» остаётся только запасным способом, например если владелец заранее скачал файл отдельно. Не выбирай варианты Google Tensor / Tensor G5/G6 или NPU-образы для других устройств.

Каталог Gemma 4 проверяет точный размер и SHA-256 по закреплённому официальному значению при завершении загрузки и повторно при каждом восстановлении сохранённой модели. Проверка также отклоняет файл, чей canonical path находится вне app-specific каталога загрузок. Это намеренно означает повторное чтение примерно 2,59 ГБ при старте модели: кэш размера/mtime не считается доказательством целостности.

Ручные команды Termux, ручная распаковка модели и ручной выбор файла для штатной установки не требуются.

## Ограничения

- Модель не вшита в APK из-за размера 2,59 ГБ, но включена отдельным файлом в единый ZIP. Android не разрешает обычному APK молча читать произвольные файлы из общей папки, поэтому после нажатия «УСТАНОВИТЬ MANA XZ» открывается штатный системный выбор файла. После одного выбора MANA автоматически копирует, проверяет и подключает модель. Альтернатива — загрузка через Android Download Manager по Wi-Fi.
- Устройство не прошло физический benchmark с Gemma 4 E2B; если памяти или ускорителя не хватит, выбери меньшую модель.
- Gradle compile проверяет сборку исходников, но не гарантирует, что конкретный файл модели загрузится на RMX5566.
- Этот Android-прототип ещё не является собранной MANA OS прошивкой.
